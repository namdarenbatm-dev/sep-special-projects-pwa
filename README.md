# برنامه پروژه‌های خاص هدایت تراکنش سپ (PWA)

داشبورد مدیریتی پروژه‌های منتخب توسعه و تأمین پایانه‌های پذیرندگی شرکت پرداخت الکترونیک سامان (سپ).

## ویژگی‌های PWA
- قابل نصب روی موبایل و دسکتاپ (Add to Home Screen)
- پشتیبانی آفلاین پایه با Service Worker
- نمایش standalone بدون نوار مرورگر
- پشتیبانی RTL و زبان فارسی

## اجرا
پس از فعال‌سازی GitHub Pages، آدرس زیر در دسترس خواهد بود:

`https://namdarenbatm-dev.github.io/sep-special-projects-pwa/`

## فایل‌ها
- `index.html` — صفحه اصلی داشبورد
- `manifest.json` — مانیفست وب‌اپلیکیشن
- `sw.js` — Service Worker
- آیکون‌ها: `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`

## نحوه نصب
1. صفحه را در Chrome یا Edge باز کنید.
2. از منوی مرورگر گزینه **Install app** یا **Add to Home screen** را انتخاب کنید.
